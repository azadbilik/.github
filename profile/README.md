## Azad Bilik

**Azərbaycan mədəniyyəti və tarixi haqqında açıq bilik:** ədəbiyyat, xəritələr, musiqi, təsviri sənət və məlumatlar. Pulsuz, açıq mənbəli, hər kəs üçün.

*Open knowledge about Azerbaijani culture and history: literature, maps, music, art and data. Free, open source, for everyone.*

### Layihələr · Projects

| | |
|---|---|
| [**kitabxana**](https://github.com/azadbilik/kitabxana) | [kitabxana.az](https://kitabxana.az): Azərbaycan ədəbiyyatının onlayn kitabxanası. Klassik və müasir əsərlər, tərcümələr, mənbə nəşrlərin skanları.<br>*Online library of Azerbaijani literature: classical and modern works, translations, scans of the source editions.* |
| [**xerite**](https://github.com/azadbilik/xerite) | [Ədəbiyyat xəritəsi](https://azadbilik.org/xerite/): müəlliflərin doğulduğu və vəfat etdiyi yerlər, əsrlər üzrə.<br>*Literary map: where the authors were born and died, century by century.* |
| [**data**](https://github.com/azadbilik/data) | Açıq məlumatlar (CC0): kitabxananın kataloqu, CSV.<br>*Open data (CC0): kitabxana's catalogue as CSV.* |

Sırada: təsvir qalereyası, musiqi arxivi.<br>
*Next: an image gallery, a music archive.*

### Prinsiplər · Principles

- **Kod açıqdır.** Hər layihənin kodu burada, hər kəs baxa və istifadə edə bilər.<br>*The code is open: every project's source is here for anyone to read and reuse.*
- **Mənbə göstərilir.** Hər mətn və təsvir götürüldüyü nəşrə bağlanır.<br>*Every text and image links back to the edition it comes from.*

### Töhfə · Contributing

Səhv tapdınız, təklifiniz və ya yeni mənbəniz var? Layihənin repozitoriyasında issue açın: azərbaycan, ingilis və ya rus dilində.<br>
*Found a mistake, have an idea or a source? Open an issue in the project's repository, in Azerbaijani, English or Russian.*
